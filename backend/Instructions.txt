These instructions are to help you compile and run backend

Prerequisites:
Java 17+
Maven 3.9+
Internet connection (for FAA SWIM API)

Maven needs to be installed.
    - Check if its already intalled. On mac try: 
    ~ mvn -v
    
If not installed, install maven on mac with:
    ~ brew install maven

For the first-time setup do:
    ~ mvn clean install

To compile first go to Capstone_Group_M/backend/
Then compile with 
    ~ mvn compile

Before running the SWIM consumer, you need an application.conf file in the
backend/ root directory. This file contains our FAA SWIM credentials and
is gitignored for security.

Create backend/application.conf with the following format:

    providerUrl:"tcps://ems1.swim.faa.gov:55443"
    queue:"<your-swim-queue>"
    connectionFactory:"<your-connection-factory>"
    username:"<your-swim-username>"
    password:"<your-swim-password>"
    vpn:"AIM_FNS"
    output:"notams_output.txt"
    json:true

If you want use the old api using "~ mvn exec:java -Dexec.mainClass="com.notam.controller.Main""
you will need to create a local enviromnent variable below are instructions
how to do so.

In terminal
    ~ export FAA_CLIENT_SECRET=<secret_key_value>

To run test simply do:
    ~ mvn test

Once compiled you can check specific .java files with:
    ~ mvn exec:java -Dexec.mainClass="your.location.yourjava"
example:
    ~ mvn exec:java -Dexec.mainClass="com.notam.controller.Main"
or run the SWIM Consumer to populate Notams directly:
    ~ mvn exec:java -Dexec.mainClass="com.notam.client.new_client.SWIMConsumer"

To run unit tests:
    ~ mvn test

To run a specific test class:
    ~ mvn test -Dtest="NOTAMTest"
